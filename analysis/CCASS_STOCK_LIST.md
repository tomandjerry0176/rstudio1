## 二、CCASS 抓取规格

| 项目 | 要求 |
|---|---|
| 日期 | **月末最后一个交易日**；能多取就从 2014-11（沪港通开通）开始，至少从 2017-03 开始 |
| 加密时点 | 每次美联储首次加息和首次降息前后各 3 个月改为周度：2015-12、2019-07、2020-03、2022-03、2024-09、2025-12、2026-09 |
| 参与者范围 | **全部参与者**，不要只取前十，否则长尾的外资券商会被漏掉 |
| 字段 | 日期、股票代码、参与者编号、参与者名称、持股数、占已发行股份比例（%）；同一日期的 CCASS 总持股、未进入 CCASS 的股份数、已发行股份总数 |
| 港股通 | 单独保留中国证券登记结算（上海、深圳）两个参与者，或另取港交所港股通持股披露 |
| H 股注意 | CCASS 的比例按 **H 股股本**计算，请同时给出 H 股股数，不要用总股本 |

## 三、配套个股数据（Wind / Bloomberg）

| 字段 | 频率 | 用途 |
|---|---|---|
| 收盘价、后复权价或全收益指数 | 日 | 个股收益 |
| 滚动股息率、一致预期股息率、DPS | 月 | 个股层面计算股息率−美债利差 |
| 除息日、股权登记日 | 事件 | 登记日前后托管转移会扭曲持股，需标记 |
| 总市值、自由流通市值 | 月 | 按市值加权汇总 |
| 港股通纳入和调出日期 | 事件 | 未纳入期间南向持股为 0，不能当作“卖出” |

## 四、参与者分类（拿到数据后由脚本统一映射）

1. **港股通**：中国证券登记结算（上海、深圳）
2. **国际托管行**：汇丰、花旗、摩根大通、渣打、法巴、德银、道富、纽约梅隆等（主要代表外资机构）
3. **外资券商**：高盛、摩根士丹利、瑞银、美林、野村等（含对冲基金和交易盘）
4. **中资券商香港子公司**：中金、中信、海通、国泰君安、华泰、招商等（客户内外资混合）
5. **本地券商和银行**：中银香港、恒生、东亚、辉立、富途等（以香港本地散户为主）
6. **其他和未入 CCASS**

需要注意：参与者只是托管或经纪通道，不等于最终投资者。其中第 1 类最干净；第 2、3 类可以作为“外资”的代理；第 4、5 类是混合的，只能看趋势。
